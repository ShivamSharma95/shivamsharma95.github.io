# 🌐 My Developer Portfolio

This is my personal developer portfolio built with **Angular**, designed to showcase my projects, skills, and professional experience. It is fully automated using **GitHub Actions** for continuous deployment and tested with **Jasmine & Karma** to ensure reliability and quality.

---

## 🚀 Tech Stack

### **Frontend**
- **Angular** (latest stable version)
- TypeScript
- HTML5, SCSS
- Responsive UI & reusable components

### **Testing**
- **Jasmine** – Unit testing framework  
- **Karma** – Test runner  
- Code coverage configuration included

### **Automation & Deployment**
- **GitHub Actions** CI/CD pipeline  
  - Install dependencies  
  - Run tests  
  - Build Angular project  
  - Deploy to GitHub Pages

### **Version Control**
- **Git & GitHub** for repository management and Actions workflow
